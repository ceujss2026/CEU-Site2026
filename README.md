# Career Education Unit (CEU) Portal 2026

Career Education Unit Portal for student pathways, scholarships, institutional profiles, and support inquiries.

## Project Structure
- `index.html` - Main portal interface with SPA routing, embedded institutional profiles, and inquiry forms.
- `Code.js` - Google Apps Script backend services (authentication, logging, inquiry submission).
- `appsscript.json` - Google Apps Script project manifest.
- `.clasp.json` - Google Clasp deployment configuration.
